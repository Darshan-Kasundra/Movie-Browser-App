# 🎬 Movie Browser

A React.js web application that allows users to **search for movies**, **view details**, and **browse movie information** using the [TMDB API](https://www.themoviedb.org/documentation/api).

---

## 🚀 Features
- 🔍 **Search movies** by title using the TMDB API  
- 🖼️ **Movie cards** with posters, titles, and detail links  
- 📖 **Detailed movie view** including title, overview, poster, and backdrop  
- 🏠 **Hero component** for page headers and backdrops  
- 📌 **Navigation bar** with search input and multiple pages (Home, About)  
- 📱 **Responsive design** with Bootstrap for mobile, tablet, and desktop  

---

## 🛠️ Tech Stack
- **Frontend:** React.js  
- **Styling:** Bootstrap 5  
- **Routing:** React Router DOM  
- **API:** TMDB REST API
